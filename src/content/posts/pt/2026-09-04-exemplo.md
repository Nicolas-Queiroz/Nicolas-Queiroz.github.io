Este post é apenas para você verificar como o layout dos artigos fica renderizado.

## Como o bot funcionará

A cada dois dias, um GitHub Action executa um script Python que:

1. Busca notícias relevantes na Currents API usando keywords do seu perfil profissional.
2. Escolhe a mais recente e relevante.
3. Envia para o Gemini gerar um post original em português e outro em inglês.
4. Salva os arquivos em `drafts/` para você revisar antes de publicar.

## Próximos passos

Depois que você validar o funcionamento local, delete este arquivo e o equivalente em inglês. Quando o bot rodar pela primeira vez, um post real vai aparecer no lugar.
